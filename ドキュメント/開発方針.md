# VRChatワールドの開発方針

## 目的と進め方

VRChatで空中にペンで図形を描き、認識した図形で敵を倒すゲームを作る。
ユーザー自身が実装を学べるよう、各段階の設定・コードの意図を説明する。
実作業の依頼があった範囲でCodexが作成・設定する。

- [工程表](工程表.md) には、全体目標・マイルストーン・目安の日程を記録する。
- [TODO](TODO.md) には、今後の作業と完了状況を記録する。
- `開発ログ/` フォルダに、日付ごとの実施内容・確認結果・未確認事項を分けて追記する。
  - [開発](開発ログ/開発.md): ゲームの仕様・実装・動作確認・開発計画。
  - [環境](開発ログ/環境.md): エディター・接続・Gitなどの設定や不具合調査。
- 作成したことと、動作を確認したことを区別する。
- コードの作成・修正・提案を始める前に [コーディング規約](コーディング規約.md) を読み、その指示に従う。書式・命名・プロパティの書き方などの合意は同文書にまとめる。

## 開発環境

- Unity 2022.3.22f1
- VRChat Worlds SDK
- UdonSharp
- 作業対象シーン: `Assets/Scenes/VRCDefaultWorldScene.unity`

## 公式資料

- [UdonSharp](https://creators.vrchat.com/worlds/udon/udonsharp/)
- [VRChat Worlds SDK](https://creators.vrchat.com/worlds/)
- [Unityスクリプトリファレンス（2022.3）](https://docs.unity3d.com/ja/2022.3/ScriptReference/)
- [Unityマニュアル（2022.3）](https://docs.unity3d.com/ja/2022.3/Manual/)

## APIを利用するときのルール

- 不慣れなAPIを使う前に、関連する公式資料を確認する。
- 通常のC#の機能が、そのままUdonSharpで使えるとは考えない。
- すべてのUnity APIがUdonに公開されているとは考えない。
- APIを使用できるか不明な場合は、UdonSharpのClass Exposure Treeを確認する。
- マルチプレイヤー機能では、VRChatのネットワーク関連資料を確認する。
- Unity 2022.3で利用できないUnity 6のAPIは使わない。
- 資料にアクセスできない場合は、何が未確認なのかを明示する。

## UdonSharpスクリプトの作成

- C#ファイルだけでなく、対応するProgram Assetの作成、Source Scriptの紐付け、コンパイル確認までを作成範囲とする。
- シーンへの取り付けは、別の依頼として扱う。
- Unity EditorのUdonSharp API（このプロジェクトの `UdonSharpHelper.EnsureProgramAsset` など）を使う。
- Program AssetのYAMLを手書きして代用しない。Unityに接続できない場合は、その制約を報告する。
- 既存の対応Assetがある場合は、重複作成しない。
- 右クリックの「Create → U# Script」と同様、同名の `.cs` と `.asset` をセットにし、参照を紐付ける。

## コードの書き方と参照の取得

プロパティでの初回取得、必須参照のエラー報告、アクセス修飾子の省略、配置と命名の具体例は [コーディング規約](コーディング規約.md) に記載する。重複した規則をここへ追加しない。

## 描画と認識の設計

- `Stroke` はユーザー指定により `Pen` の子オブジェクトにする。
- 線はワールド座標で表示する。
- 認識用の2D投影と、表示用の3D軌跡を分けて扱う。
- Pickupの設定だけではペンの移動や描いた線は他プレイヤーへ同期されない。共有範囲を決めてから同期を実装する。
