# VR空中描画ゲームの作業一覧

更新日: 2026-10-14

作業の進め方は [開発方針](開発方針.md)、実施内容と確認結果は [作業ログ](作業ログ.md) を参照。

## 現在の段階: ペンの基本操作

- [x] 細長いCubeの `Pen` を作成（2.5cm × 2.5cm × 20cm）
- [x] 子オブジェクト `PenTip` を先端に配置
- [x] BoxCollider、Rigidbody、VRC Pickupを付ける
- [x] 重力OFF、Is Kinematic ONを確認
- [ ] VRChatで拾う・動かす・手放す動作を確認
- [ ] Auto Holdと握る位置・向きを確認し、必要に応じて調整

## 次の段階: 一筆描画

- [x] 練習用 `Assets/LineRendererExample.cs` を作成（Startで3点の折れ線を表示）
- [x] 対応する `Assets/LineRendererExample.asset` を用意し、Source Scriptを紐付ける
- [ ] 練習用Program Assetのコンパイル済みプログラムを個別に確認
- [ ] 練習用スクリプトのStrokeへの取り付け、Line参照、マテリアルを確認し、実際に表示する
- [x] `Pen` の子に空の `Stroke` とLineRendererを用意
- [ ] 線のマテリアル・太さ・ワールド座標での表示を確認
- [ ] UdonSharpでトリガーの押下・解放を受け取る
- [ ] 描き始めに前の線を消す
- [ ] 描画中はPenTipが一定距離動くごとに座標を記録し、線に追加
- [ ] 最大点数を決めて配列の上限を処理
- [ ] トリガーを離したら描画を終了し、線を残す
- [ ] 描画中にペンを手放した場合も描画を終了
- [ ] VRで線がペン先から出て、手放しても位置が変わらないことを確認

## 後の段階: 図形認識とゲーム

- [ ] 描き始めのHMDの右・上方向を保存し、一筆の間は固定
- [ ] 3D軌跡を固定した基底へ投影し、奥行きを無視した2D軌跡を生成
- [ ] 点間隔・位置・大きさを揃え、お手本との比較を実装
- [ ] 対応する図形と判定基準を決める
- [ ] 認識結果を表示して精度を検証
- [ ] 敵のマークと認識結果を結び付ける
- [ ] マルチプレイヤーで共有する範囲を決め、必要なら同期を実装
